# RandomUserAPI
Приложение для взаимодействие с API RandomUser (Тестовое задание, YADRO)

1. Клонируйте репозиторий:
```bash
git clone https://github.com/KenyaProgressive/BuisnessDev2025_Case
cd BuisnessDev2025_Case
```

2. Создайте виртуальное окружение и активируйте его:
```bash
python -m venv .venv
source .venv/bin/activate  # для Linux/MacOS
.venv\Scripts\activate     # для Windows
```
3. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Структура проекта

- `src/` - основной код приложения
  - `api/` - функции для взаимодействия с API
  - `UI/` - HTML-файлы и настройка Jinja2
  - `log/` - лог-файлы
- `db/` - функции для работы с базой данных


## Запуск проекта

1. Запустите приложение:
```bash
cd src
python main.py
```
> Первый запуск может производиться до 150 секунд, 
> т.к. создаётся БД и загружаются данные. Последующие запуски будут быстрыми.

3. Откройте браузер и перейдите по адресу: http://localhost:8000

## Использование приложения

- http://localhost:8000 -- начальная страница с информацией о пользователях. 
По умолчанию выводится 10 строк информации. При увеличении числа выводимых строк выше 50, выводиться будет только 50, а остальные записи будут появляться по мере нажатия кнопки "Развернуть".
- http://localhost:8000/random -- страница со случайно выбранной карточкой пользователя из БД. При обновлении страница, карточка будет подбираться заново
- http://localhost:8000/<user_id> -- страница с конкретно выбранной карточкой пользователя. Можно получить доступ через нажатия кнопки на главной странице или через ввод номера пользователя из БД.

## Стек

В качестве веб-фреймворка был выбран FastAPI, т.к. является актуальным для рынка и очень удобным инструментом при разработке веб-приложений.
В качестве БД была выбрана sqlite3. Она являеться частью стандартной библиотеки Python и очень проста в использовании. Её мощности хватает для работы с данными пользователей.


## Слабые стороны приложения

При загрузке новых строк основной таблицы, фотографии пользователя могут не прогрузиться сразу. Это происходит из-за большого количества запросов к sqlite, конфликтующих между собой. При перезагрузке страницы / входе на карточку клиента фотография загружается успешно.
Загрузка фотографий сделана таким образом, потому что ссылки на фото, генерируемые API, не являются рабочими, потому что randomuser.me недоступен в РФ
